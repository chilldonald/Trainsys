# 🏋️ Trainsys — Tracker for Workouts & Analytics

Веб-приложение на **Django** для трекинга спортивных тренировок, учёта выполненных упражнений, расчёта общей нагрузки и наглядной аналитики прогресса.

---

## 🚀 Основные возможности

- **Управление тренировками** — добавление тренировок с набором упражнений (подходы, повторения, вес), просмотр истории и деталей каждой тренировки.
- **Аналитика и прогресс** — расчёт предполагаемого одноповторного максимума (1RM) по формуле Эпли, подсчёт суммарного тоннажа и динамические графики нагрузки.
- **Профиль пользователя** — персональная статистика (количество тренировок, суммарный поднятый вес, MMR) и встроенная система аутентификации.
- **Безопасность и архитектура** — разграничение прав доступа (`@login_required`), защита от повторной отправки форм, хранение конфигурации в переменных окружения.

## 💻 Локальный запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/Trainsys.git
cd Trainsys
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация:

```bash
# Linux / macOS
source venv/bin/activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1

# Windows (Git Bash)
source venv/Scripts/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создай файл `.env` в корне проекта:

```env
SECRET_KEY=your_secret_key_here
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost
```

### 5. Миграции и запуск

```bash
python manage.py migrate
python manage.py runserver
```

Приложение будет доступно по адресу: <http://127.0.0.1:8000/>
